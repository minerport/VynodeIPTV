# 0.18.0 — Sports explorer and direct For You navigation

- Browser: 56 behavior tests passed. Desktop and 390px phone UI fixture exercised standings search/conference filters, team comparisons/categories, player leaders and career seasons, schedules, modal closure, channel options, and page overflow. One duplicated ESPN event yields one game with two possible channels; an active EPG slot cannot mark a future game LIVE.
- Android: debug APK build, 77 JVM tests and lint passed (0 errors, 44 warnings). VersionName 0.18.0, versionCode 40; existing application/signing identity and Material 3 1.3.2 pin retained. API-30 emulator verified the new sidebar shortcut, real server-linked standings, four-team comparisons, team stats, player leaders/career and schedules using isolated synthetic provider data and public ESPN responses.
- Backend: tests cover authenticated access, fixed destinations, invalid teams/seasons/athlete IDs, bounded cache, failure backoff/stale expiry, and large leader-response trimming. Full Go suite and vet passed. Linux race tests and synthetic media/recovery smoke gate container publication.
- Live public-source checks: all five league scoreboards, NFL team schedule/statistics, leaderboards and athlete career data. ESPN date-range scoreboard requests returned 400, so the implementation merges the current scoreboard with team schedules by event ID. NFL leader data exceeded 2 MiB; its bounded 8 MiB source read is trimmed to displayed fields before caching (about 25 KiB in the checked response). Other endpoints retain a 2 MiB limit.
- Only a fresh scoreboard can certify in-progress status. Schedules and EPG channel matches cannot certify a live broadcast; potential provider channels are labeled accordingly. Missing leagues/seasons/player categories show unavailable states rather than invented data. Player leaderboards are source category leaders, not a complete roster database.
- Physical Shield installation/startup and public container verification are release checks; Unraid container update and end-to-end provider game availability remain user-host acceptance checks.
